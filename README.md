## 👋 About Me

I'm a **Senior C++ Systems Engineer** with **8.5+ years** of experience designing, building, and optimizing high-performance software across **Web Content Management, FinTech, Telecom, and Embedded Systems** domains.

- 🚀 I build low-latency, high-throughput systems using **Modern C++ (C++11/14/17)** and strong software design fundamentals
- 🐧 Deep hands-on expertise in **Linux internals**, POSIX APIs, process management, and systems-level programming
- 🌐 Passionate about **distributed systems**, client-server architectures, and scalable backend infrastructure
- ⚡ Specialize in **performance engineering** — memory optimization, core dump analysis, deadlock/thread-contention debugging, and root cause analysis
- 🧠 Strong believer in clean **system design**, SOLID principles, and maintainable, testable code
- 📚 Constant learner — currently deep-diving into **C++20/23**, cloud-native systems, and open-source contribution
