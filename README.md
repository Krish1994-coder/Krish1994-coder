### 🌐 Distributed In-Memory Data Storage & Loader

🔒 **Private repository — available to authorized reviewers/collaborators**

A **C++17 distributed in-memory data storage and loading system** that simulates a **1–5 node cluster in a single process**.

The implementation includes:

- Deterministic hash-based data partitioning
- Local and remote record routing
- Batched transport over a mock socket-style network layer
- Concurrent loader and receiver threads
- In-memory key-value storage
- Deterministic duplicate-key resolution
- Per-node load and network statistics
- End-to-end ownership and correctness verification
- Unit tests and automated build/run scripts

`C++17` `Distributed Systems` `Partitioning` `Concurrency` `Batching` `Mock Networking` `In-Memory Storage` `Verification`
